# Proyecto HU - Sistema de Gestión de Versiones con Git

Este proyecto consiste en la creacoin de los Archivos principales de una aplicación web básica, con el propósito práctico de consolidar los fundamentos de los sistemas de control de versiones distribuidos mediante **Git** y la posterior sincronización con repositorios remotos en la plataforma **GitHub**.

## 🚀 Tecnologías Utilizadas

* **HTML5:** Para estructuración semántica del documento base de la aplicación.
* **CSS3:** Para gefinición de hojas de estilo para la presentación y el diseño visual.
* **Git:** Gestión, control de versiones local e historial de desarrollo a través de la terminal.
* **GitHub:** Alojamiento en la nube para el repositorio remoto y herramientas de colaboración.

## 🗂️ Estructura del Proyecto

El repositorio local está compuesto por los siguientes archivos esenciales:
* `index.html`: Archivo principal de estructura web.
* `styles.css`: Hoja de estilos vinculada para el diseño visual.
* `README.md`: Este archivo de documentación técnica.

## 🕒 Historial de Versiones (Commits Coherentes)

El proyecto fue estructurado y auditado en la terminal de comandos de Windows PowerShell a través de tres commits:

1. `Creación de index.html`: Inicialización y maquetación de la estructura principal del index.
2. `Creación de styles.css`: Adición de reglas de diseño y estilos CSS al proyecto.
3. `Creación README para registrar proceso`: Generación de este archivo de documentación para el despliegue técnico.

Para verificar la secuencia cronológica y la integridad del árbol de Git de manera local, se puede ejecutar el comando estructurado:
```bash
git log --oneline
```
